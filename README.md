# Puzzles and games

Static collection, no build step. Serve the folder over HTTPS (e.g. GitHub Pages); index.html links to each game subfolder. Add future games as new subfolders plus a card on index.html - old games stay put.

- wordle-alarm/ - daily Wordle-style word alarm (own word list, midnight IST rollover). See wordle-alarm/README.md.
- pushup-alarm/ - camera-counted push-up alarm with reworked counter (side-on or front-on). Front-on fix validated on prerecorded video only; real-phone retest pending. Tap button is the backup. See pushup-alarm/README.md.

Demos only: a page cannot wake a locked phone.
